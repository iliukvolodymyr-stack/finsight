## 3. Дрібні рішення

- Індикатори: власна реалізація на pandas/numpy (`ta` малопідтримуваний, TA-Lib не збирається на Windows); `ta`/TA-Lib — лише «оракул» у тестах.
- `.npmrc` з `node-linker=hoisted` для Expo + pnpm.
- UUIDv7 у Python 3.12 не вбудований: `uuid-utils`.
- OOF для meta-моделі в часовому ряду — внутрішній walk-forward.
- Slug'и LLM-моделей у `.env.example` позначено як плейсхолдери: звірити з OpenRouter.
- Додано тести: `test_label_backtest_consistency`, `test_news_availability`, `test_fold_scoped_fit`.

## 4. Відкриті питання (не вирішуються документом)

1. **Історичні новини.** Який публічний датасет (і з якою ліцензією) підходить для бекфілу? Від цього залежить, чи E3 буде доказовим, чи попереднім.
2. **Вимоги кафедри.** Чи достатньо для курсової desktop без mobile; обсяг записки; чи потрібен акт впровадження (розділ 12 у 05).
3. **Capacity.** Якщо реальна ємність < 20 год/тиждень, застосувати «мінімум курсової» (05 §3.2) уже з 24.11, а не з 10.12.
4. **Назви моделей LLM** (DeepSeek/Qwen/Gemini з ТЗ): перевірити, що вони існують у каталозі провайдера на дату старту D2.
